# 写作与出图规范

所有章节（含后续本地修改）都按这份规范写，保证全文记号、风格和证据标注一致。

## 语言与结构

- 正文用简体中文，学术但好读：先给结论，再给推导和证据。避免空话和堆砌术语，第一次出现的术语给中文名和英文原名，如“按分匹配（skill-based matchmaking, SBMM）”。
- 每章以 `\begin{answerbox} ... \end{answerbox}` 开头，用 3–8 句话直接回答该研究的问题。
- 节标题写成结论句或明确的问题，不写“概述”“讨论”这类空标题。
- 公式要能复现：给出假设、推导（短的放正文 `derivbox`，长的放 `chapters/appendix_chN.tex`）、数值例子。重要公式编号并用 `\cref` 引用。
- 不同“形式”分小节展示：例如 1v1 / 团队 / 多人自由混战；随机匹配 / 按分匹配；不同的实力波动模型。
- 不写“早期笔记”“核查发现”之类的过程性旁白；直接写核查后的结论。访问失败等检索细节放在引言“方法与局限”或 `docs/TO_VERIFY.md`，正文只写“本文未能核实全文”。
- 术语统一见引言的术语对照表：评分（MMR、隐藏分）、可见段位、组排（不用“车队”）、输家队列（首次出现注 loser queue）、检验力（不用“功效”）、蒙特卡洛、逻辑斯蒂。

## 证据标签（宏在 `paper/preamble.tex`）

每条事实性陈述后标注来源性质：

| 宏 | 显示 | 含义 |
|---|---|---|
| `\tagLit` | 【文献】 | 同行评审论文或公司技术报告；只有 arXiv 预印本、尚无同行评审版本的也用它，但首次出现时注明“预印本” |
| `\tagOff` | 【官方】 | 开发商官方博客、白皮书、员工公开发言（含媒体转述的员工原话）；法院案卷、判决与法规文本本身 |
| `\tagPat` | 【专利】 | 专利文献：只说明申请过，不说明已部署 |
| `\tagCom` | 【社区】 | 玩家、自媒体、第三方工具、百科：未经证实 |
| `\tagOwn` | 【本项目】 | 本项目自己的推导或模拟；必须给出参数 |

- 诉讼材料分两层：立案、开庭、判决、撤诉等程序事实和判决理由标 `\tagOff`；起诉状或当事人陈述中的**指控**（如“连胜后会配坑队友”）标 `\tagCom`，并写明是原告的说法。
- 没读到原文全文、只依据摘要或转述的来源：正文加 `\needcheck`，并登记到 `docs/TO_VERIFY.md`（写明原因，如“付费墙，需校园网”）。多人并行写作时先写各自的 `docs/to_verify_chN.md`，整合时并入。
- “无需操纵即可解释”不等于“已证明没有操纵”；措辞上保持这个区分。

## 记号（全文统一）

| 记号 | 含义 |
|---|---|
| $s_i$ | 玩家 $i$ 的真实实力（潜变量，Elo 刻度） |
| $\mu,\tau$ | 群体实力的均值、标准差（默认 $\tau=200$） |
| $R_i$ 或 $R_{i,t}$ | 系统对实力的估计（评分、隐藏分、MMR） |
| $F(x)=1/(1+10^{-x/400})$ | Elo 胜率曲线，宏 `\Elogit` |
| $c=\ln 10/400$ | Elo 曲线在 0 处的斜率常数，$F'(0)=c/4$ |
| $E$ | 系统预测胜率 $F(R_i-R_j)$ |
| $p$ | 真实单局胜率 $F(s_i-s_j)$ |
| $y\in\{0,1\}$ | 单局结果（Elo 文献中的 $S$） |
| $K$ | K 因子；$T$ 局数 |
| $n$ | 每队人数；$N$ 每局人数（自由混战） |
| $\sigma_q$ | 排队/匹配噪声（匹配窗口宽度） |
| $\sigma_e$ | 评分围绕实力的稳态误差标准差 |
| $\lambda$ | 评分刻度相对实力刻度的伸缩系数 |
| $u_t$ | 实力波动（状态），$s_{i,t}=s_i+u_t$ |
| $\Phi$ | 标准正态分布函数 |
| $\Lambda(x)$ | 逻辑斯蒂函数 $1/(1+e^{-x})$（不用 $\sigma(\cdot)$，避免与标准差混淆） |
| $\rho$、$b$ | AR(1) 状态的自回归系数；评分每局吸收的比例（第二、三章通用） |
| $\ind\{\cdot\}$ | 示性函数（宏 `\ind`，不要用 `\mathbb 1`） |

## 参考文献

- 每章写自己的 bib 文件：`paper/refs/ch1a.bib`、`ch1b.bib`、`ch2.bib`、`ch3.bib`、`ch4.bib`；整合时合并去重为 `paper/refs/refs.bib`。
- 键名规则：第一作者姓（小写、去空格和连字符）+ 年份 + 标题第一个实词（小写），如 `elo1978rating`、`herbrich2006trueskill`、`minka2018trueskill`。官方博客用公司名：`riot2018matchmaking`。
- 条目必须来自真实来源：有 DOI 写 DOI，有 URL 写 `url` 和 `urldate`（2026-10）。中文条目加 `langid = {chinese}`。

## 出图

- 用 `code/figstyle.py`：`use()` 设置全局风格，`save(fig, "chN", "name")` 同时输出 `figures/chN/name.pdf`（论文）和 `.png`（幻灯片/预览）。
- 每个图一个脚本 `code/chN/fig_<name>.py`，可独立运行、固定随机种子、几分钟内跑完；需要重模拟的，把模拟结果缓存到 `code/chN/cache/*.npz`，脚本发现缓存就直接画。
- 配色按 `SERIES` 固定顺序取，不循环；不画双纵轴；线宽约 1.6；网格浅；≥2 个系列要有图例，≤4 个系列尽量直接标注；文字用墨色而不是系列颜色。
- 坐标轴标签写中文并带单位/记号，如“评分差 $R_A-R_B$（Elo）”。
- 图注（caption）写清“图在说明什么结论”，并给出模拟参数。
- 出图后用 PNG 看一遍：标签有没有重叠、图例有没有挡住数据、字号在版心宽度下能不能读。

## 编译

```bash
cd paper && latexmk -xelatex main.tex      # 论文
cd slides && latexmk -xelatex slides.tex   # 幻灯片
python code/run_all.py                     # 重新生成全部图（或 python code/run_all.py ch2）
```
