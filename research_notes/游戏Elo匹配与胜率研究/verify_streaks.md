## A. 精确数学（`python verify_streaks.py A` → `partA_out.md`）

**最长连败。** 我用 Markov 链（状态 = 当前尾部连败长度，到达 r 即吸收）计算 P(L_n<r)，再与原文的首胜分解递推 a_n=Σ_{j<r} q^j p a_{n−j−1} 逐项比较，五个检查点一致到 1e-5：0.81011、0.31752、0.98178、0.38545、0.68167。A1 全表 12 格（E、SD、中位数、95 分位、P≥5/7/10/12、期望段数）与原文逐位一致。MC（3–10 万条序列）：n=100 均值 5.990，P≥5 为 0.809；n=1000 为 9.301 / P≥10 0.383；p=.45 为 10.690 / 0.6835。GSW 近似 log_{1/q}(np)+γ/ln(1/q)−½ 的最大误差为 0.035。经验法则 log₂(n/2) 给出 5.6 / 9.0，与精确值相比约低 0.3。"≥r 连败段期望个数" q^r[1+(n−r)p] 的推导正确，与原文表一致。

**W^kL^k 计数。** 子串 W^kL^k 的 border 为空，所以两次出现不能重叠。每次出现恰好跨越一个 W→L 边界，且左侧 W 游程 ≥k、右侧 L 游程 ≥k；反过来，每个这样的边界恰好对应一次出现。因此 E=(n−2k+1)(pq)^k 是"≥k 连胜后紧接 ≥k 连败"这一事件个数的**精确**期望。MC 的子串计数和按游程对计数都吻合（例如 p=.5、k=4、n=1000：3.879 / 3.877 / 3.899；p=.45：3.726 / 3.718 / 3.743）。**误读风险**：(i) 它不同于"恰好 4 胜接恰好 4 负"（0.97 / 千局）；(ii) 它不同于"两种顺序都算"（7.76 / 千局；100 局内至少一次的概率为 49.8%，不是 31%）；(iii) "4 连胜后 4 连败"要求两段紧挨着，而玩家主观上的"连胜后连败"往往更宽松，实际频率会更高。

**Miller–Sanjurjo。** 精确 DP 的状态为（截断的连胜长度、试验数 c、成功数 w）。n=20 的结果 0.4737 / 0.4151 / 0.3613 与 2^20 穷举一致；n=100 时 k=1..5 为 0.4949 / 0.4843 / **0.4603** / 0.4125 / 0.3649，与原文 A4d（MC）一致到 ±0.002；n=1000、k=3 为 0.4967，k=5 为 0.4841。合并所有历史计数时为 0.500。注意：这个偏差属于"每人自己的比率再求平均"这一估计量；如果每段连胜只取一次观测，偏差几乎消失（0.505）。

**团队稀释。** 1v1 +100 → 0.6401；5v5 均值模型 f(100/5) → 0.5288；加和/√5 → 0.5640；Thurstone 加和加个人噪声（β 校准到同一 1v1 曲线）→ 0.5637。所以 52.9% 是均值模型下的结果。`winrate_math.md` 另外使用了加和模型，两份笔记应统一说明这一点。

**归因（解析 MC，随机房间、iid 实力）。** P(最弱者是队友 | 负) = 0.472，P(… | 胜) = 0.330，与原文的随机房间行（0.471 / 0.329）一致。

## C. 原文中我认为需要在最终报告里保留或补充的限定
1. Part B 的所有数字都是**模型输出**：正态实力、Elo 模型本身设定正确、固定 K、封闭人群、全员每轮都打、无组排。核心效应量（W5 −3.0pp、P≥10 40%→29%、F1 +77 Elo）只在 σ=100 / 250 下成立，应写成区间（如 K32：−0.7~−3.1pp），并注明 σ=100 接近上限。
2. "玩家内部超额"用的是模型里的**真实单局胜率**，真实数据中观测不到。实证中只能用实际胜负，必须同时做 Miller–Sanjurjo 修正和构成效应控制（原文已经提到）。
3. E（连胜加分）、K64、F2 以及任何真正按 MMR 平衡的 5v5，评分尺度在测量期内都**不平稳**，数值只是某一时刻的快照。原脚本 docstring 写的"measured phase is a converged / stationary Elo system"并不普遍成立；docstring 里写的"queue noise N(0,25²)"也与实际默认值（100 / 250）不符。
4. D5 措辞：−21 Elo 是"**5 连胜后**"的玩家内部超额，而且只在随机分队或按带噪键蛇形分队时成立；"赢一局后"只有 −4。如果真实游戏按 MMR 平衡分队，诚实基线约为 −6，而 loser-queue 式操纵约为 −30。这时"队友比我低"本身的判别力比原文暗示的要强，但仍不如"敌我队均分差"干净。
5. A6/A7 的"31%""3.9 次"要明确事件定义：顺序为"胜在前"、两段紧挨、各自至少 k 局。不分顺序时为 50% 和 7.8 次。
6. 团队稀释的 52.9% 取决于团队强度用均值模型；用加和模型为 56.4%，与 `winrate_math.md` 的口径不同。
7. 连败的精确数学只对"独立、p 恒定"成立。Part B 的打乱基线显示，个人胜率的异质性会让基线 P(≥10) 从 0.385 升到约 0.39–0.42。

## D. 读原脚本后的差异诊断（判定完成后才读）
- **"5v5 平衡分队"并不是按 MMR 平衡。** `streaks_sim.py` 中 `split='balanced'` 的分支是 `A, B = lob[:, [0,3,4,7,8]], lob[:, [1,2,5,6,9]]`，`lob` 是按**带噪排队键**（R + N(0,250²)）排好的顺序。噪声远大于房间内的评分差，所以这实际上是随机分队。这正是原文表中"平衡分队"与"随机分队"几乎完全相同（斜率 1.39 对 1.37，B7 0.454 对 0.453）的原因。我按同样方式实现的 `snake_key` 完全复现了原文（W5 −0.51，斜率 1.40，队友−我 −20.4，0.454 / 0.346）。改为按真实 MMR 蛇形后：尺度无界拉伸，W5 −0.35 并继续变小，诚实的"队友−我"只有 −5.6，最弱队友 0.424 / 0.376。另外，F2（`balanced_manip`）**是**按 MMR 蛇形的，所以原文用的"诚实平衡分队"并不是 F2 的同类对照。F2 的结论（敌我差 +35 对诚实 −4 / −0.1）不受影响。
- 其余实现（Elo 更新、连胜加分只乘赢家收益、操纵键、玩家内部超额的权重、W^kL^k 计数、游程检验、ρ 与 n*）与我的独立实现等价，数值差异都在 MC 噪声以内。上头场景中，原脚本的"对手实力"用的是含上头的有效实力，我用的是 θ，只影响上头场景的对手实力列。
