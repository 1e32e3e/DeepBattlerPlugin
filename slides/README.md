## 页面大纲（43 页 = 标题页 + 5 张节标题页 + 37 张内容页）

**问题与结论速览**
1. 四个问题的答案：胜率能算，“Elo 感”无需操纵即可解释
2. “每局五五开”是预测胜率五五开，不是实力五五开

**研究一：文献、厂商披露、专利与诉讼**
3. 评分与匹配是两层机制：“控胜率”若存在，只能在匹配层（三层结构示意图）
4. 评分模型百年：逐条放松“两人、实力固定、一维”三个假设（`ch1/1a_timeline`）
5. 匹配研究的目标：公平即信息量最大，留存是另一回事（参与度匹配效应量表）
6. 厂商原话：被拉平的是预测胜率，长期 50% 只是“副作用”
7. 专利：EA 的权利要求写明按“流失风险”组局，但专利不证明部署
8. 两起诉讼都没有裁定“胜率是否被操纵”（Zajonc 诉 EA；孙千和诉腾讯）
9. 证据分三档：已证实 / 被否认 / 仍未知

**研究二：不干涉匹配时，胜率能否计算**
10. 实力、评分、胜率是三个量（`ch2/three_quantities` (a)）
11. “五五开”的一局，真实胜率在 38%–62% 之间（`ch2/fair_game`）
12. 随机匹配：胜率只由实力百分位和运气比例决定（`ch2/random_1v1` (a)）
13. 按分匹配把实力兑换成评分，长期胜率被压向 50%（恒等式；`ch2/sbmm_deciles` (a)）
14. 段位与分数只通过对手起作用：重置到 1500 的高手前 50 局胜率 77.5%（`ch2/reset` (b)）
15. 团队稀释个人优势：约按 1/√n 到 1/n（`ch2/team` (a)）
16. 8 人局的基准取决于“胜”的定义（Plackett–Luce；`ch2/ffa` (a)）
17. 实力有波动时期望仍可算，但窗口胜率更分散（`ch2/ar1` (b)）
18. 区分 52% 与 50% 约需 4,900 局（`ch2/ci` (b)）

**研究三：诚实系统会不会制造“Elo 感”**
19. 纯随机已足以制造长连败（`ch3/longest_run` (a)）
20. “连胜紧接连败”和低谷窗口同样常见（`ch3/pattern_window` (a)）
21. 自查战绩的陷阱：Miller–Sanjurjo 偏差与构成效应（`ch3/ms_bias` (a)）
22. 诚实 Elo 自带均值回归（`ch3/elo_reversion` (b)）
23. 五种实力波动模型（`ch3/models_traj` 中 AR(1) 与上头两条轨迹）
24. 上头：连败触发的自激（`ch3/tilt_chain` (a)）
25. 评分吸收慢状态，只有上头显著放大连串（模型比较表）
26. 操纵的指纹在匹配输入里（`ch3/manip` (b)）
27. 酒馆战棋：久不夺冠是常态（`ch3/bg_drought`）

**研究四：训练视角——目标是胜率还是实力**
28. 标签是胜负，输出是胜率，被学到的是实力（`ch4/fig_calibration` (b)）
29. Elo 是在线逻辑回归：K 就是学习率（`ch4/fig_k_tradeoff` (b)）
30. 收敛后每局像抛硬币，而五五开的对局信息量最大（`ch4/fig_fisher` (a)）
31. 以冻结、校准过的收敛模型为零假设检验残差（`ch4/fig_residual_tests` (c)）
32. 自博弈：进步要对固定参照池来量（`ch4/fig_selfplay_inflation` (a)）
33. 酒馆战棋 AI：名次似然训练，冻结参照池评估（`ch4/fig_bg_placement` (b)）

**结论与下一步**
34. 一条主线：胜率不是实力，评分是带噪估计，匹配器只看得到评分
35. 结论的边界：理想化模型、示意参数、没有真实匹配日志
36. 下一步一：把“控胜率”说法写成匹配规则，模拟出它们的指纹
37. 下一步二：用本人的对局数据估计实力曲线与波动范围
